Deliverables
- pyproject.toml: project "qwen-asr-mini-tool", requires-python ">=3.11" (Ubuntu 24.04 ships 3.12; 3.11 kept so the current dev venv can run the suite), dependencies = every current requirements.txt dependency PLUS the direct declarations ticket 01 found missing/transitive: tokenizers, kaldi-native-fbank, soundfile, soxr, scipy, certifi. Optional extras: "qr" = [segno]; "windows" = [pywebview] (native window only); "gpu" = contents of requirements-gpu.txt; "dev" = [pytest]. customtkinter stays a main dependency (browser backend still imports the Tk graph transitively - documented transitional coupling). Keep comments explaining Windows-only extras.
- uv.lock generated with "uv lock" (uv is at /home/claude/.local/bin/uv). If a package cannot be resolved for some platform, adjust markers minimally and note it.
- requirements.txt becomes GENERATED: regenerate it with "uv export --format requirements-txt --no-hashes --no-emit-project --no-dev -o requirements.txt" (verify exact flags with uv export --help) and add a header comment "GENERATED by uv export - do not hand-edit; see scripts/check-requirements-sync.sh". The Windows "pip install -r requirements.txt" flow must keep working (pins are fine).
- scripts/check-requirements-sync.sh: exits non-zero with a diff when requirements.txt differs from a fresh uv export. Plus tests/test_packaging.py: pyproject parses (tomllib), lists the required direct deps, extras exist; requirements sync test that runs the same comparison and is skipped (pytest.skip) when uv is not on PATH.
- run.sh (executable, bash, set -euo pipefail): Ubuntu launch gate. Refuses with the fixing command when uv is missing ("install uv: https://docs.astral.sh/uv/") or when the env is out of date: use "uv sync --check" if this uv supports it (check uv sync --help) else "uv lock --check"; both are local, no network. Then exec "uv run python preflight.py" if preflight.py exists (it will land in ticket 02 - guard with a file test) and finally "exec uv run python app_webview.py". Print bilingual (English + 繁體中文) one-liners for each refusal.
- docs/ubuntu-prerequisites.md: the apt list (python3, python3-venv, python3-tk, ca-certificates, ffmpeg, xdg-utils) + uv install command + "models and VAD are downloaded by the application". Keep it short; ticket 13 writes the full guide and links here.
Do not change build_venv.bat, build.bat or any Windows flow.
